韓国で使う地図アプリ：NAVER Map・KakaoMap・Google Mapsの使い方

韓国ではNAVER Mapをメインのナビアプリとして使うのがおすすめです。KakaoMapを予備にし、Google Mapsは保存した場所、口コミ、旅行全体の計画に使うと役割を分けやすくなります。

韓国到着前に地図アプリを準備する

安定したWi-Fiが使えるうちに、アプリ、言語設定、テスト用の1ルートまで準備しておきます。

  1. NAVER Mapをインストール

    　やること：公式アプリをダウンロードし、一度起動します。

    うまくいかない場合：アプリストアで「NAVER Maps, Navigation」を検索し、開発元がNAVER Corp.であることを確認します。

  2. KakaoMapを予備としてインストール

    　やること：別ルートや現地情報のクロスチェックに使えるよう準備します。

    うまくいかない場合：NAVER Mapを使い、必要なときにKakaoMap公式Webサービスを開きます。

  3. Google Mapsも残す

    　やること：保存済みの場所、共有リスト、使い慣れた旅行計画をそのまま使います。

    うまくいかない場合：場所名や住所を現地の地図アプリへコピーして最終ルートを確認します。

  4. 位置情報へのアクセスを許可

    　やること：出発地点を正確にするため、各アプリで「使用中のみ位置情報を許可」にします。

    うまくいかない場合：スマートフォンのプライバシーまたはアプリ権限設定を開き、正確な位置情報を有効にします。

  5. NAVER Mapを英語表示にする

    　やること：MY → Settings → Language → Englishを選びます。

    うまくいかない場合：iPhoneではSettings → NAVER Map → Preferred Languageを使います。

  6. ホテルの韓国語名と住所を保存

    　やること：正確な施設情報、韓国語の道路名住所、電話番号を保存します。

    うまくいかない場合：ホテルまたは予約確認書から韓国語表記をコピーします。

  7. 空港からホテルまでのルートを1本テスト

    　やること：正しい空港ターミナルを設定し、公共交通と最後の徒歩を比べます。

    うまくいかない場合：スクリーンショットを保存し、到着後にもう一度ルートを確認します。

リアルタイム経路はモバイルデータがあるほうが使いやすくなります。韓国用eSIMを準備し、eSIMの選択肢を比較し、必須アプリガイドを確認して、これらの準備を韓国旅行チェックリストにも追加しておきましょう。

NAVER Mapを英語で使う方法

初期設定から、最後の地下鉄出口やバス停まで、この順序で使うと分かりやすくなります。

A. アプリの表示言語を英語にする

Android

MY → Settings → Language → English

iPhone

MY → Settings → Language

必要な場合：iPhone Settings → NAVER Map → Preferred Language → English

B. 場所を検索する

情報を少しずつ具体的にして検索します。英語で一度見つからなかったからといって、その場所が登録されていないとは限りません。

  • 英語の施設名
  • 英語の道路名住所
  • 韓国語の施設名
  • 韓国語の道路名住所
  • 電話番号

C. 正しい支店・店舗か確認する

ホテル、カフェ、レストランは、別のエリアに同じ名前の支店があることがあります。ルートを開始する前に掲載情報を確認してください。

  • エリア・地区
  • 韓国語の道路名住所
  • 電話番号
  • 写真
  • 最寄り地下鉄駅
  • 駅からの距離
  • 営業時間情報

D. 経路を検索する

  • 現在地または別の出発地点を設定します。
  • 確認済みの目的地を選びます。
  • 公共交通または徒歩を選びます。
  • 所要時間、乗り換え、最後の徒歩距離を比較します。
  • Wi-Fiを離れる前にルートを保存します。

E. 地下鉄出口を確認する

  • 駅名だけでは不十分です。
  • 電車を降りる前に出口番号を確認します。
  • その出口が道路のどちら側に出るかを確認します。
  • 大きな駅では、駅構内を長く歩く場合があると考えておきます。

F. バス停を確認する

  • 似た名前の停留所が複数あることがあります。
  • 停留所番号または進行方向を確認します。
  • 乗車前にバスの行き先を確認します。
  • 最後の徒歩区間も確認します。

G. 場所を保存・共有する

  • ホテルと正確な空港ターミナルを保存します。
  • レストランは支店を確認してから保存します。
  • 韓国語住所をテキストでもコピーしておきます。
  • 旅行同行者には、正確な場所のリンクを共有します。

英語検索で見つからないとき

翻訳された名前ではなく、実際の韓国語登録情報へ切り替えて検索結果を探します。

  1. 英語名で見つからない
  2. 公式の韓国語名を探す
  3. 韓国語表記をコピーする
  4. NAVER Mapに貼り付ける
  5. 住所・電話番号・写真を確認する
  6. 必要ならKakaoMapでも確認する

韓国語名を見つける場所

  • ホテルまたは予約確認書
  • 店舗・施設の公式Webサイト
  • 公式Instagramプロフィール
  • Google検索結果
  • 韓国語の道路名住所
  • 電話番号

それでも違う結果が出る理由

  • 予約サイトの名称と現地登録名が違う。
  • 別支店が同じ名前を使っている。
  • レストランが建物名で登録されている。
  • 店舗が移転・閉店した、または期間限定ポップアップである。
  • 地下街の中に店舗がある。
  • 英語表記のつづりが複数ある。

KakaoMapを予備として使う場面

確認が必要なとき、KakaoMapは現地情報の2つ目の結果として役立ちます。メインアプリを置き換える必要はありません。

  • NAVER Mapの検索結果が分かりにくい。
  • 別の徒歩ルートも比べたい。
  • バス情報をクロスチェックしたい。
  • 現地の人からKakaoの場所リンクを送られた。
  • 場所名や住所を確認したい。
  • 深夜移動の前に別ルートも確認したい。

まずNAVER Map → 確認や別ルートが必要なときKakaoMap。

韓国でGoogle Mapsにできること・できないこと

Google Mapsは残しておきましょう。ただし、今すでに使える機能と、今後改善される可能性がある機能は分けて考える必要があります。

韓国政府は2026年2月、厳格な安全保障条件のもとでGoogleによる1:5,000地図データの国外搬出を承認しました。今後の機能改善につながる可能性はありますが、展開時期や利用できる機能は端末・経路・地域によって今も異なる可能性があります。

現時点で役立つ使い方

  • 旅行前に場所を保存する。
  • 共有リストを整理する。
  • 海外旅行者の口コミを読む。
  • 都市全体の位置関係を把握する。
  • 使い慣れたGoogleの場所情報を共有する。
  • 自分の端末で現在使える機能を確認する。

重要：徒歩、車、ナビゲーションのすべての機能がすでに完全対応しているとは考えないでください。自分の端末で実際のルートを確認し、NAVER MapまたはKakaoMapも使えるようにしておきます。

Googleのオフラインマップ

  • 国や地域によっては地図をダウンロードできない場合があります。
  • オフラインでは公共交通、徒歩、自転車の経路案内は利用できません。
  • リアルタイムのナビゲーションや経路変更には、引き続きモバイルデータが重要です。

実際の旅行場面で地図を使い分ける

ターミナル、支店、出口、停留所の方向、営業時間など、ルートを変える要素から確認します。

  1. 仁川空港からホテルへ

    • 　正確なターミナルとホテルの韓国語住所を保存します。
    • 空港鉄道、バス、最後の徒歩を比較します。
    • 全行程の比較には空港送迎ガイドを使います。
    • ターミナルや到着手続きが計画に影響する場合は、仁川空港ガイドと到着ガイドも確認します。

  2. ホテルからレストランへ

    • 　レストランの韓国語名で検索します。
    • 支店、営業時間情報、最後の徒歩を確認します。
    • 問題がホテルの場所や駅アクセスなら、宿泊ガイドを使います。

  3. 正しい地下鉄出口を探す

    • 　電車を降りる前に出口を確認します。
    • 道路の向きと、エレベーターが必要かどうかも確認します。

  4. 市内バスに乗る

    • 　停留所の方向、バス番号、行き先を確認します。
    • 降車停留所と最後の徒歩区間も確認します。

  5. 深夜に戻る

    • 　最後に使える公共交通を確認します。
    • タクシーの乗車地点をクロスチェックし、タクシーガイドもすぐ開けるようにします。

  6. 待ち合わせ場所を共有する

    • 　正確な場所の掲載情報と韓国語住所または名称を共有します。
    • エリア名だけを送らないでください。

地図アプリでよくある失敗

小さな確認だけで、「違う場所」「反対方向」というよくある失敗の多くを防げます。

  • 英語だけで検索する　韓国語名、道路名住所、電話番号も用意します。
  • 支店を間違える　エリア、写真、最寄り駅を照合します。
  • 地下鉄出口を確認しない　電車を降りる前に出口を確認します。
  • 実際の出発時刻ではなく予定到着時刻で検索する　実際に出発する時間でルートを設定します。
  • 合計所要時間だけを比べる　乗り換え、待ち時間、安定性も確認します。
  • 荷物があるのに最後の徒歩を無視する　列車区間が短くても、最後に大変な徒歩が残ることがあります。
  • バス停の反対側を選ぶ　乗車前に方向または停留所番号を確認します。
  • 結果が曖昧なのに一つのアプリだけを信じる　KakaoMapなど別の掲載情報でも確認します。
  • モバイルデータなしで空港を出る　リアルタイムナビに頼る前にeSIM、SIM、ローミングを有効にします。

よくある質問

旅行中によく困る地図アプリの問題を、短く実用的にまとめています。

韓国で一番使いやすい地図アプリは？

多くの旅行者にはNAVER Mapが最初の選択肢です。現地の場所検索と、徒歩・地下鉄・バスの経路を一つで確認できます。KakaoMapを予備にし、Google Mapsは旅行計画、保存した場所、海外旅行者の口コミに使うと便利です。

NAVER Mapは英語で使える？

はい。アプリでMY → Settings → Language → Englishを開きます。iPhoneでは、Settings → NAVER Map → Preferred Languageへ移動する場合があります。

韓国でGoogle Mapsは使える？

はい。保存した場所、共有リスト、海外旅行者の口コミ、旅行全体の計画に役立ちます。ただし、経路・ナビ機能の利用状況は今も異なることがあるため、自分の端末で実際のルートを確認し、現地地図アプリも用意してください。

KakaoMapも入れたほうがいい？

便利な予備ですが、すべての旅行者に必須ではありません。場所をクロスチェックしたい、別の徒歩ルートを比べたい、バス情報を確認したい、Kakaoの場所リンクを開きたい場合に入れておくと役立ちます。

英語検索で見つからないときは？

予約情報、店舗の公式サイト、信頼できる掲載情報から正式な韓国語名または道路名住所を探してください。それをNAVER Mapへ貼り付け、住所、電話番号、写真を照合します。

正しい地下鉄出口はどう探す？

電車を降りる前にルートを開き、出口番号、道路のどちら側に出るか、残りの徒歩を確認します。大きな駅では、エレベーターが必要か、駅構内をどの程度歩くかも確認してください。

反対方向のバス停を選ばないためには？

乗車前に停留所番号または進行方向、バスの行き先、道路のどちら側かを確認します。似た停留所名でも、進行方向が反対の場合があります。

韓国でオフラインマップは使える？

Googleは、国や地域によってオフライン地図をダウンロードできない場合があり、オフラインでは公共交通、徒歩、自転車の経路案内を利用できないと案内しています。自分の端末でダウンロード可否を確認し、リアルタイムナビ用にモバイルデータを確保してください。

ホテルの住所を保存・共有するには？

NAVER Mapで正確なホテル情報を保存し、韓国語のホテル名と道路名住所をコピーして同行者に場所リンクを共有します。予約確認書にも韓国語テキストを残しておいてください。

韓国の地図アプリにモバイルデータは必要？

経路変更、リアルタイム交通情報、施設情報、共有にはモバイルデータを強くおすすめします。リアルタイムナビに頼る前にeSIM、SIM、ローミングを準備してください。
