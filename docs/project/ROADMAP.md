# Korea Inside Roadmap

## Role

This file records long-term direction and stages. It is not a page execution queue and does not authorize Codex to select or start the next task.

## Long-term Stages

1. Build and validate useful problem-solving travel content.
2. Strengthen the website's decision-support structure and trusted source coverage.
3. Validate traffic, demand, content structure, and revenue signals.
4. Consider PWA or mobile-app expansion only when validated user needs justify it.

## Core Principle

Build useful problem-solving travel pages first.

Do not build a mobile app before validating traffic, demand, content structure, and revenue model.

Specific pages and priorities belong in a user-approved task or the explicitly designated latest handoff, not in this roadmap.
