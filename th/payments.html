Korean mobile payment apps จ่ายประจำวันเมื่อผ่าน verification และ payment setup ที่เข้ากันได้ ฟีเจอร์บางอย่างอาจต้อง Korean identity verification, Korean phone service หรือบัญชีธนาคารเกาหลี

จุดที่บัตรต่างประเทศยังมีปัญหาได้

การจ่ายสำเร็จที่ร้านหนึ่งไม่ได้รับประกันว่าบัตรเดียวกันจะใช้ได้ที่ร้านถัดไป Merchant terminal, card network, issuer setting และวิธี authentication ของ transaction เปลี่ยนผลได้ทั้งหมด

Acceptance ต่างกันตามร้านและ terminal

บัตรสากลหลัก เช่น Visa, Mastercard, JCB, Amex และ UnionPay ใช้ได้ในร้านเกาหลีจำนวนมาก แต่ acceptance ยังต่างตามร้านและเครื่อง Contactless ไม่ได้มีทุกแห่ง ขณะที่ตลาด สตรีทสตอลล์ และธุรกิจเล็กมากบางแห่งอาจใช้เงินสดง่ายกว่า

Online checkout อาจขอข้อมูลท้องถิ่น

บัตรต่างประเทศที่ใช้หน้าร้านได้อาจใช้บนเว็บไซต์เกาหลีไม่ได้ เมื่อ checkout ต้อง local authentication, Korean phone verification หรือ domestic payment flow

Mobile wallet มีกฎ setup ของตัวเอง

Apple Pay ใช้ได้ที่ร้าน NFC ที่เข้าร่วม แต่บัตรใน Wallet และ terminal ของร้านยังต้องเข้ากัน บริการเกาหลีอย่าง Kakao Pay และ Naver Pay อาจต้อง local identity, phone หรือ payment setup จึงไม่ใช่ default ที่ควรพึ่งในทริปสั้น ส่วน mobile wallet อื่นขึ้นอยู่กับบัตร อุปกรณ์ และ service setup ของตัวเอง

เงินขนส่งอาจอยู่คนละยอด

การเติม T-money อาจใช้ payment flow คนละแบบกับการซื้อของหน้าร้าน ในบัตรนักท่องเที่ยวแบบ multi-function ยอดขนส่งกับ prepaid payment balance ก็อาจแยกกัน

การจ่ายแท็กซี่ยังสะดุดได้

แท็กซี่จำนวนมากรับบัตรหรือ T-money แต่ terminal issue, card type และเงื่อนไขท้องถิ่นยังสร้าง friction ได้

เงินสดยังมีประโยชน์กับธุรกิจเล็กสุด

ตลาด สตรีทสตอลล์ และร้านเล็กบางแห่งอาจไม่ใช้รูปแบบบัตรเดียวกับโรงแรมและร้านเชน เงินสดจำนวนเล็กน้อยช่วยผ่านช่วงเหล่านี้โดยไม่ต้องใช้เงินสดทั้งทริป

หาเงินสดในเกาหลี

ATM ที่รับบัตรต่างประเทศมีตามสนามบิน ธนาคาร และบางร้านสะดวกซื้อหรือสถานี แต่การรองรับต่างกันตามเครื่อง

ต้นทุนสุดท้ายของการถอนหรือแลกเงินขึ้นอยู่กับ ATM operator, card issuer, network fee และอัตราแลกเปลี่ยน

ทิปและหารบิล

เกาหลีไม่ได้คาดหวังหรือมีธรรมเนียมให้ทิป Service charge ก็ไม่ค่อยถูกบวก การหารบิลพบได้ทั่วไป และร้านอาหารจำนวนมากยอมให้แยกจ่ายด้วยบัตร พูดว่า “ttaro gyesanhae juseyo” เมื่อต้องการขอแยกจ่าย

คำถามที่พบบ่อย

ใช้บัตรเครดิตต่างประเทศในเกาหลีได้ไหม?

ได้ บัตร Visa และ Mastercard ต่างประเทศใช้ได้ในหลายแห่ง แต่ร้านเล็ก บริการออนไลน์ และ terminal บางประเภทอาจรับต่างกัน

ต้องมีเงินสดในเกาหลีไหม?

ควรมีเล็กน้อยสำหรับตลาดดั้งเดิม ร้านเล็ก payment backup และบางกรณีเติมบัตรขนส่ง

Apple Pay หรือ Google Pay ใช้ในเกาหลีได้ไหม?

ใช้ได้บางกรณี ขึ้นอยู่กับบัตร wallet setup และ terminal ของร้าน อย่าให้เป็นวิธีจ่ายเพียงอย่างเดียว

T-money เป็นบัตรจ่ายเงินไหม?

T-money ใช้หลักๆ สำหรับขนส่ง ใช้ได้กับแท็กซี่บางคันและร้านสะดวกซื้อบางสถานการณ์ แต่ไม่ใช่บัตรช้อปปิ้งทั่วไป

WOWPASS ดีกว่า T-money ไหม?

WOWPASS อาจเหมาะกว่าเมื่อคุณต้องการ prepaid payment และ currency exchange ส่วน T-money ง่ายกว่าถ้าต้องการแค่รถไฟใต้ดินและรถบัส

จ่ายแท็กซี่ด้วยบัตรได้ไหม?

แท็กซี่จำนวนมากรับบัตร แต่ควรมีวิธีสำรองเพราะ card type, terminal issue หรือเงื่อนไขท้องถิ่นอาจต่างกัน

ทำไมบัตรใช้บนเว็บไม่ได้?

บริการออนไลน์เกาหลีบางแห่งต้อง Korean identity verification, Korean phone number หรือ domestic payment authentication

แอปจ่ายเงินเกาหลีใช้กับนักท่องเที่ยวได้ไหม?

ฟีเจอร์บางอย่างอาจจำกัดเพราะ setup เต็มรูปแบบต้อง Korean identity verification, Korean phone service หรือบัญชีธนาคารเกาหลี
