## Coverage method

Each nonempty text node containing letters, relevant language attribute, JSON-LD user-facing string, and explicitly inventoried inline-JS UI string is a source location. Repeated occurrences count separately. Numbers-only tokens, whitespace and punctuation-only tokens are technical/nonlinguistic and preserved. Proper names can legitimately be unchanged and are reported separately. Protected navigation/footer locations are reported separately and reduce whole-page French coverage. Inline-JS strings are reviewed per page and added to totals when present.
